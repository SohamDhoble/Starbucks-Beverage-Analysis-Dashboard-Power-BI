# ☕Starbucks-Beverage-Analysis-Dashboard-Power-BI
A visually interactive Power BI dashboard analyzing Starbucks beverage data, featuring KPI cards, dynamic slicers, category-wise comparisons, caffeine and sugar analysis, calorie insights, and nutritional trends. Designed with Starbucks-inspired branding to deliver clear, data-driven insights through engaging and interactive visualizations.
☕ Starbucks Beverage Analysis Dashboard
📌 Project Overview
The Starbucks Beverage Analysis Dashboard is an interactive Power BI project developed to analyze and visualize nutritional information across Starbucks beverages. The dashboard helps users explore beverage categories, compare nutritional values, and identify high-caffeine drinks through intuitive visualizations.
🎯 Objectives
Analyze Starbucks beverage nutritional data.
Compare calorie, sugar, and caffeine content across beverage categories.
Identify the highest caffeine beverages.
Provide interactive filtering for deeper exploration.
Create a professional and visually appealing dashboard using Power BI.
